# animwarp / animwarpend 애니메이션 주석 사용 사양

## 1. 개요

`animwarp`는 하나의 애니메이션 구간(segment)에 포함된 수평 루트 모션을 조절하여, 구간이 끝날 때 액터가 현재 전투 대상에 더 가까이 도달하도록 합니다. `animmotion`이 제공하는 X/Y 변위만 배율 조정합니다.

- 원래 이동 방향을 회전하거나 변경하지 않습니다.
- Z축 모션은 조절하지 않습니다.
- 다른 애니메이션에는 영향을 주지 않습니다.
- 배율을 적용하려면 유효한 현재 전투 대상이 필요합니다.
- 명시적 `animwarp`를 사용하면 비전투 애니메이션에서도 워핑을 활성화할 수 있습니다.

## 2. 주석 문법

    animwarp <최소배율> <최대배율> [최대각도] [최대거리]
    animwarpend

모든 `animwarp` 인수는 0 이상의 부동소수점 숫자입니다.

- `최소배율`: 해당 구간에서 허용되는 최소 수평 배율입니다.
- `최대배율`: 해당 구간에서 허용되는 최대 수평 배율입니다.
- `최대각도`: 선택 사항이며, 원래 이동 방향과 대상 방향 사이의 최대 각도입니다. 기본값은 60도입니다.
- `최대거리`: 선택 사항이며, 현재 액터와 대상 사이의 최대 수평 거리입니다. 기본값은 무제한입니다.
- `0 <= 최소배율 <= 최대배율`이어야 합니다.
- 최대각도는 0–180도 범위여야 합니다.

인수는 위치에 따라 해석됩니다. 최대거리를 지정하려면 최대각도도 먼저 지정해야 합니다.

예시:

    animwarp 0 1

수평 변위를 0%까지 줄일 수 있지만 원래보다 늘리지는 않습니다.

    animwarp 0.5 1.5

원래 수평 변위의 50%–150%를 허용합니다.

    animwarp 0 1.5 60 300

최대 각도 60도, 현재 수평 대상 거리 300 Skyrim 단위 이내에서 0%–150% 배율을 허용합니다.

    animwarpend

이 타임스탬프부터 다음 `animwarp`가 나올 때까지 모션 워핑을 비활성화합니다.

    animwarp 1 1

`animwarpend`와 완전히 같은 의미입니다. 유효한 선택적 각도나 거리 인수는 이 의미를 바꾸지 않지만, 잘못된 선택 값은 여전히 전체 주석을 잘못된 형식으로 만듭니다.

## 3. 구간 규칙

각 `animwarp`는 자신의 타임스탬프에서 새 구간을 시작합니다. 구간은 다음 중 가장 먼저 발생하는 지점에서 끝납니다.

1. 다음 `animwarp`
2. 다음 `animwarpend`
3. `animmotion` 곡선의 끝

구간은 `[시작, 끝)` 형태의 반개구간입니다. 정확한 종료 타임스탬프는 다음 구간에 속하며, 한 게임 업데이트가 경계를 가로지르는 경우에도 동일합니다.

예시:

    0.20초: animwarp 0 1 45 250
    0.60초: animwarp 0.5 1.5 90 400
    1.00초: animwarpend
    1.40초: animwarp 0 1

동작:

- 0.00–0.20초: 워핑 없음
- 0.20–0.60초: 배율 0–1, 최대각도 45, 최대거리 250
- 0.60–1.00초: 배율 0.5–1.5, 최대각도 90, 최대거리 400
- 1.00–1.40초: 워핑 없음
- 1.40초 이후: 다음 제어 주석 또는 곡선 끝까지 배율 0–1

같은 타임스탬프에 여러 제어 주석이 있으면 애니메이션 데이터에서 더 뒤에 위치한 주석이 이후 상태를 결정합니다.

## 4. 명시적 제어와 기본 공격 워핑

예약된 `animwarp` 또는 `animwarpend` 제어가 하나라도 있으면 전체 애니메이션이 명시적으로 제어됩니다.

- 전체 애니메이션에서 기본 공격 워핑이 억제됩니다.
- 첫 번째 유효한 `animwarp` 이전에는 워핑하지 않습니다.
- `animwarpend` 이후에는 다른 `animwarp`가 나오기 전까지 워핑하지 않습니다.
- 유효한 명시적 구간은 액터가 공격 중이 아니어도 워핑할 수 있습니다.
- `bEnableForAttackAnimations = false`는 명시적 구간을 비활성화하지 않습니다.

형식이 잘못된 예약 제어도 기본 공격 워핑을 억제하며 로그 경고를 생성합니다. 이 실패 안전 동작은 오타 때문에 암시적 규칙이 의도치 않게 활성화되는 것을 방지합니다.

`animwarp` 또는 `animwarpend` 제어가 전혀 없는 애니메이션만 기본 공격 워핑을 사용할 수 있습니다.

## 5. 기본 공격 애니메이션의 자동 구간 분할

애니메이션에 명시적 제어가 없고 INI에서 기본 공격 워핑이 활성화되어 있으면, AMR은 0초부터 암시적 기본 구간이 시작된 것으로 처리합니다. 초기 기본값은 다음과 같습니다.

- 최소배율: 0
- 최대배율: 1
- 최대각도: 60도

AMR은 다음 이벤트마다 현재 기본 구간을 끝내고 즉시 새 기본 구간을 시작합니다.

- 대소문자를 구분하지 않는 정확한 `HitFrame` 이벤트. `HitFrame.$payload`도 지원합니다.
- 대소문자를 구분하지 않고 `Collision_Add`로 시작하는 이벤트. `Collision_Add.Node(WEAPON)` 같은 값도 지원합니다.

예시:

    0.00초: 암시적 기본 animwarp
    0.70초: HitFrame
    1.10초: Collision_Add.Node(WEAPON)

이 경우 `[0.00, 0.70)`, `[0.70, 1.10)`, `[1.10, animmotion 끝]`의 세 구간이 생성됩니다. 각 새 구간은 현재 대상에 맞춰 배율을 다시 계산하므로 연속 타격을 각각 독립적으로 정렬할 수 있습니다.

같은 타임스탬프의 여러 충돌 이벤트는 하나의 경계로 병합됩니다. `preHitFrame`, `NPCHitFrame`, `2_HitFrame` 같은 이름은 `HitFrame`으로 잘못 인식되지 않습니다.

## 6. 구간 변위와 배율 계산

AMR은 정확한 경계에서 누적 모션을 샘플링합니다.

    원래구간변위 = animmotion(구간끝) - animmotion(구간시작)
    원래수평거리 = lengthXY(원래구간변위)

정상적으로 새 구간에 진입할 때:

    요청배율 = max(0, 수평대상거리 - 정지거리) / 원래수평거리
    최종배율 = clamp(요청배율, 최소배율, 최대배율)

최종배율은 구간 전체의 X/Y 루트 모션에 균일하게 적용되며 Z는 변경되지 않습니다. 구간 끝점은 애니메이션 활성화 시 한 번 샘플링되어 캐시되고, 대상과 적용 조건이 유지되는 동안 배율도 캐시됩니다.

대상이 변경되거나 거리 조건이 다시 유효해지거나 기본 공격 워핑이 구간 중간에 활성화되면, AMR은 현재 애니메이션 커서부터 같은 구간 끝까지 남은 원래 변위만 사용하여 다시 계산합니다. 이미 소비된 모션은 다시 계산하지 않습니다. 이 과정도 상수 시간 벡터 계산입니다.

원래 수평 거리가 100인 구간의 예:

- 필요한 이동이 30이고 `animwarp 0 1`이면 0.3
- 필요한 이동이 180이고 `animwarp 0 1`이면 1.0으로 제한
- 필요한 이동이 180이고 `animwarp 0 2`이면 1.8
- 필요한 이동이 10이고 `animwarp 0.5 1`이면 0.5로 제한

한 업데이트가 구간 경계를 가로지르면 AMR은 해당 업데이트를 나눕니다. 경계 이전 모션에는 이전 구간을, 경계 이후 모션에는 새 구간을 적용합니다. 여러 경계를 가로지른 경우 순서대로 모두 처리하여 모션 손실이나 인위적인 정지를 방지합니다.

## 7. animmotion과의 관계

`animwarp`는 루트 모션을 생성하지 않습니다. 애니메이션에는 여전히 유효한 `animmotion` 데이터가 필요합니다.

    0.00초: animmotion 0 0 0
    0.50초: animmotion 0 50 0
    1.00초: animmotion 0 100 0
    0.20초: animwarp 0 1.5
    0.70초: animwarpend

명시적 워핑 구간은 `[0.20, 0.70)`이고 원래 변위는 `animmotion(0.70) - animmotion(0.20)`입니다. 0.20초 이전과 0.70초 이후 모션은 워핑되지 않습니다.

수평 `animmotion`이 충분하지 않거나 INI의 `fMinimumAuthoredDistance`보다 짧은 구간은 워핑되지 않습니다.

## 8. 대상, 방향 및 거리 조건

구간에 워핑을 적용하려면:

- 액터에게 유효한 현재 전투 대상이 있어야 합니다.
- 대상이 살아 있어야 합니다.
- 액터와 대상이 같은 셀에 있어야 합니다.
- 구간의 원래 이동 방향과 대상 방향 사이의 각도가 설정된 최대값을 넘지 않아야 합니다.
- 최대거리를 지정했다면 현재 수평 거리가 그 값을 넘지 않아야 합니다.

거리 조건 밖에서는 원래 모션이 그대로 재생됩니다. 액터가 유효 범위에 다시 들어오면 워핑을 재계산하고 재개할 수 있습니다.

`animwarp`는 배율만 조절하며 회전하지 않습니다. 대상이 액터 뒤에 있거나 구간 방향이 각도 조건을 만족하지 않으면 AMR은 애니메이션을 대상으로 돌리지 않습니다. 뒤로 이동한 뒤 앞으로 이동하는 애니메이션은 독립적으로 계산할 단계 사이에 별도의 `animwarp`/`animwarpend` 경계를 배치하십시오.

## 9. Z축과 낭떠러지 보호

- 모션 워핑은 X/Y만 조절하며 원래 Z축 루트 모션은 유지됩니다.
- Z축 루트 모션이 하나라도 있는 애니메이션은 낭떠러지 이동 제한을 건너뜁니다.
- 구간 분할은 이 규칙을 변경하지 않습니다.

## 10. TrueHUD 디버그 표시

`AMR_ENABLE_TRUEHUD_DEBUG`로 컴파일한 경우:

- Page Up은 모션 워핑 표시를 전환합니다.
- Page Down은 낭떠러지 보호 표시를 전환합니다.
- 두 키는 표시만 변경하며 게임플레이에는 영향을 주지 않습니다.

모션 워핑 표시는 활성화 순간의 액터 위치와 방향을 사용하여 1초 동안 유지되는 스냅샷을 생성합니다.

- 명시적 구간 또는 자동 생성된 기본 전투 구간이 시작될 때 스냅샷을 그립니다.
- 공격 상태, 대상, 각도 또는 거리 조건이 바뀌어 이미 진행 중인 유효 구간에 워핑이 처음 적용되면 그때도 새 스냅샷을 그립니다.
- 노란색은 해당 구간의 전체 원래 `animmotion` 변위를 나타냅니다.
- 위로 띄운 청록색은 워핑이 적용될 때 예상되는 배율 적용 변위를 나타냅니다.
- `animwarpend` 이후 구간을 포함한 비활성 구간에는 워핑 스냅샷을 그리지 않습니다.
- 이전의 대상 지점과 연결선은 그리지 않습니다.

스냅샷은 그려진 뒤 액터 회전에 따라 회전하지 않으며, 길이는 시간에 따라 줄어들지 않고 항상 전체 구간을 나타냅니다.

## 11. 잘못된 주석

잘못된 제어의 예:

    animwarp -1 1
    animwarp 1 0.5
    animwarp abc 1
    animwarp 0
    animwarp 0 1 -10
    animwarp 0 1 181
    animwarp 0 1 60 -50
    animwarp 0 1 60 300 extra
    animwarpend extra

잘못된 제어는 유효한 명시적 타임라인을 변경하지 않지만, 해당 애니메이션의 기본 공격 워핑은 계속 억제합니다. 경고는 `AnimationMotionRevolution.log`에서 확인하십시오.

## 12. 권장 패턴

명확한 한 단계에서 축소만 허용:

    0.20초: animwarp 0 1
    0.75초: animwarpend

연장은 금지하면서 완전 정지는 방지:

    animwarp 0.25 1

적당한 연장 허용:

    animwarp 0 1.25

여러 공격 단계를 독립적으로 계산:

    0.20초: animwarp 0 1.2
    0.70초: animwarp 0 1.1
    1.15초: animwarpend

필요한 경우에만 최대배율을 1보다 크게 설정하십시오. 과도한 연장은 구간 안의 모든 수평 변위를 증폭하여 미끄러짐이나 부자연스럽게 빠른 돌진을 만들 수 있습니다.
