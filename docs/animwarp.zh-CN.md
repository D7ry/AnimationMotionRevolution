# animwarp / animwarpend 动画注释使用规范

## 1. 功能概述

`animwarp` 用于按“时间段（segment）”缩放单个动画的水平根运动，使角色在该段结束时更接近当前战斗目标。它只缩放 `animmotion` 的 X/Y 位移：

- 不旋转或改变动画原本的移动方向；
- 不缩放 Z 轴位移；
- 不影响其他动画；
- 角色必须拥有有效的当前战斗目标，才能执行缩放；
- 非战斗动画也可以通过显式 `animwarp` 启用运动扭曲。

## 2. 注释语法

    animwarp <下限> <上限> [最大角度] [最大距离]
    animwarpend

`animwarp` 的参数均为非负浮点数：

- 下限：该段允许的最小水平缩放倍率；
- 上限：该段允许的最大水平缩放倍率；
- 最大角度：可选，该段原始移动方向与目标方向的最大夹角，默认为 60 度；
- 最大距离：可选，角色与目标的当前水平距离上限，默认为无限制；
- 必须满足 `0 <= 下限 <= 上限`；
- 最大角度必须在 0–180 度之间。

参数按位置解析。如果需要填写最大距离，必须先填写最大角度。

示例：

    animwarp 0 1

允许把该段水平位移减少到 0%，但不允许延长。

    animwarp 0.5 1.5

允许该段使用 50%–150% 的水平位移。

    animwarp 0 1.5 60 300

允许 0%–150% 缩放，最大夹角为 60 度，并且只在当前水平目标距离不超过 300 个 Skyrim 单位时生效。

    animwarpend

从该时间戳开始关闭运动扭曲，直到后面出现新的 `animwarp`。

    animwarp 1 1

与 `animwarpend` 完全同义：它结束当前扭曲段，并关闭后续扭曲，直到出现新的 `animwarp`。角度或距离参数即使写在 `animwarp 1 1` 后面也不会改变这一语义。

## 3. 分段规则

每条 `animwarp` 从自身时间戳开始一个新段。该段在以下最先发生的位置结束：

1. 下一条 `animwarp`；
2. 下一条 `animwarpend`；
3. `animmotion` 曲线末尾。

段采用 `[开始时间, 结束时间)`：结束时间戳精确属于下一段。因此，一帧即使跨过注释时间戳，也不会把下一段提前到时间戳之前。

示例：

    0.20 秒: animwarp 0 1 45 250
    0.60 秒: animwarp 0.5 1.5 90 400
    1.00 秒: animwarpend
    1.40 秒: animwarp 0 1

对应行为：

- 0.00–0.20 秒：不扭曲；
- 0.20–0.60 秒：倍率范围 0–1，最大角度 45 度，最大距离 250；
- 0.60–1.00 秒：倍率范围 0.5–1.5，最大角度 90 度，最大距离 400；
- 1.00–1.40 秒：不扭曲；
- 1.40 秒以后：倍率范围 0–1，直到下一控制注释或曲线末尾。

如果多条控制注释位于完全相同的时间戳，动画数据中排列更后的注释决定后续状态。

## 4. 显式注释与默认攻击扭曲

只要动画中出现任何保留的 `animwarp` 或 `animwarpend` 控制注释，该动画就被视为“显式控制”：

- 整个动画不再使用默认攻击扭曲；
- 第一条有效 `animwarp` 之前不扭曲；
- `animwarpend` 之后不扭曲，除非后面再次出现 `animwarp`；
- 有效 `animwarp` 段即使在角色不处于攻击状态时也可以生效；
- INI 中 `bEnableForAttackAnimations = false` 不会关闭显式 `animwarp` 段。

保留关键字写错参数时同样会关闭该动画的默认攻击扭曲，并在日志中报告无效注释。这是故障安全行为：注释写错不会意外让整段动画使用默认扭曲。

只有完全没有 `animwarp` / `animwarpend` 控制注释的动画，才可能使用 INI 中的默认攻击扭曲。

## 5. 默认攻击动画的自动分段

当动画没有任何显式扭曲控制，并且 INI 开启默认攻击扭曲时，AMR 会把它视为从 0 秒开始的默认 `animwarp` 段。默认倍率和角度来自 INI，初始值为：

- 下限 0；
- 上限 1；
- 最大角度 60 度。

AMR 会在每个以下事件处结束当前默认段，并立即开始一个使用相同默认参数的新段：

- `HitFrame`（大小写不敏感，也支持 `HitFrame.$payload`）；
- 名称以 `Collision_Add` 开头的事件（大小写不敏感，也支持 `Collision_Add.Node(WEAPON)` 等任意后缀载荷）。

例如：

    0.00 秒: （隐式默认 animwarp）
    0.70 秒: HitFrame
    1.10 秒: Collision_Add.Node(WEAPON)

会生成三个段：`[0.00, 0.70)`、`[0.70, 1.10)`、`[1.10, animmotion 末尾]`。每个新段都会重新根据当前目标距离计算倍率，因此连续攻击的每次命中都可以重新瞄准目标，而不是只在整条动画开头计算一次。

同一时间的多个碰撞节点会合并成一个边界。`preHitFrame`、`NPCHitFrame`、`2_HitFrame` 等并不会被误判为 `HitFrame`。

## 6. 段位移与倍率计算

一段的原始累积位移按边界精确采样：

    段原始位移 = animmotion(段结束时间) - animmotion(段开始时间)
    段原始水平距离 = lengthXY(段原始位移)

正常进入新段时，根据该段开始时的角色位置和目标位置计算：

    请求倍率 = max(0, 目标水平距离 - 停止距离) / 段原始水平距离
    最终倍率 = clamp(请求倍率, 下限, 上限)

最终倍率统一应用于该段的 X/Y 根运动；Z 轴保持原样。只要目标和启用条件保持不变，倍率会在该段内缓存，而不是每帧重新扫描动画曲线。段的开始/结束位移在动画激活时只采样一次，所以运行时计算是常数时间的向量运算。

如果目标切换、距离门限先失效后重新满足，或默认攻击扭曲在段中途才启用，AMR 会从当前动画游标重新计算。此时分母改为“段结束累积位移 - 当前累积位移”，只使用尚未播放的剩余位移；这样已经消耗的运动不会被重复计算，剩余运动仍然以同一个段终点为目标。该计算同样只是一次向量减法。

例如，一段原始水平距离为 100：

- 需要移动 30，`animwarp 0 1` 得到 0.3；
- 需要移动 180，`animwarp 0 1` 被限制为 1.0；
- 需要移动 180，`animwarp 0 2` 得到 1.8；
- 需要移动 10，`animwarp 0.5 1` 被限制为 0.5。

如果一帧从旧段跨到新段，AMR 会把该帧拆成两部分：边界以前按旧段处理，边界以后按新段处理。如果一帧跨过多个边界，则依次处理所有部分。这样不会在 `animwarp`、`animwarpend`、`HitFrame` 或 `Collision_Add` 处丢失一帧位移，也不会产生人为停顿。

## 7. 与 animmotion 的关系

`animwarp` 不会创建根运动。动画仍然需要有效的 `animmotion`，例如：

    0.00 秒: animmotion 0 0 0
    0.50 秒: animmotion 0 50 0
    1.00 秒: animmotion 0 100 0
    0.20 秒: animwarp 0 1.5
    0.70 秒: animwarpend

此时显式扭曲段为 `[0.20, 0.70)`，其原始位移由 `animmotion(0.70) - animmotion(0.20)` 决定；0.20 秒以前和 0.70 秒以后都不扭曲。

如果某段没有足够的水平 `animmotion`，或水平距离小于 INI 的 `fMinimumAuthoredDistance`，该段不会执行运动扭曲。

## 8. 目标、方向和距离门限

每个要执行扭曲的段都必须满足：

- 角色拥有有效的当前战斗目标；
- 目标未死亡；
- 目标与角色处于同一 Cell；
- 段原始移动方向与目标方向的夹角不超过最大角度；
- 如果填写了最大距离，当前水平距离不超过该值。

超过最大距离时，该段暂时按原始根运动播放；重新进入范围后可以重新计算并恢复扭曲。

`animwarp` 只缩放，不旋转。如果目标在角色身后，或段位移方向不符合角度限制，AMR 不会把动画转向目标。若一个动画先后向后和向前移动，应在希望独立计算的阶段之间放置新的 `animwarp` / `animwarpend` 边界。

## 9. Z 轴与悬崖保护

- 运动扭曲只缩放 X/Y；动画的 Z 轴根运动保持不变；
- 带有任何 Z 轴根运动的动画会跳过悬崖边缘移动限制；
- 分段不会改变以上规则。

## 10. TrueHUD 调试显示

编译时启用 `AMR_ENABLE_TRUEHUD_DEBUG` 后：

- Page Up：切换运动扭曲显示；
- Page Down：切换悬崖保护显示；
- 两个按键只控制显示，不改变实际功能。

运动扭曲显示会在扭曲段激活时，按激活瞬间的角色位置和朝向绘制“完整当前段”的一次性快照：

- 每次显式 `animwarp` 段开始，以及每个自动生成的默认战斗段开始时，只绘制一次快照；快照持续 1 秒，不再每帧重复绘制；
- 如果段开始时尚未实际执行扭曲，而后因攻击状态、目标、角度或距离条件变化首次开始执行，也会在该时刻绘制一次新快照；
- 黄色箭头：该段原始 `animmotion` 位移；
- 青色箭头：该段经过当前倍率缩放后的预测位移，整体抬高 8 个单位；仅在该次激活实际执行扭曲时显示；
- 非启用段（包括 `animwarpend` 后的区间）不绘制运动扭曲快照；
- 不再绘制目标脚下的红点或目标连接线。

箭头固定在快照触发瞬间的位置和朝向，不会在段内随角色转向逐帧更新；箭头长度始终表示完整段位移，不会随着时间缩短。

## 11. 无效注释

以下注释无效：

    animwarp -1 1
    animwarp 1 0.5
    animwarp abc 1
    animwarp 0
    animwarp 0 1 -10
    animwarp 0 1 181
    animwarp 0 1 60 -50
    animwarp 0 1 60 300 extra
    animwarpend extra

无效控制不会改变已经建立的显式时间轴，但它仍会使该动画退出默认攻击扭曲。请检查 `AnimationMotionRevolution.log` 中的警告并修正注释。

## 12. 推荐写法

仅允许缩短一个明确阶段：

    0.20 秒: animwarp 0 1
    0.75 秒: animwarpend

避免距离过近时完全停止，同时禁止延长：

    animwarp 0.25 1

允许适度延长：

    animwarp 0 1.25

多段攻击分别计算：

    0.20 秒: animwarp 0 1.2
    0.70 秒: animwarp 0 1.1
    1.15 秒: animwarpend

建议只在实际需要时把上限设为大于 1。过度延长会放大该段内所有水平位移，并可能产生滑步或高速冲刺。
