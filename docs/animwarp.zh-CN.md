# animwarp 动画注释使用规范

## 1. 功能概述

animwarp 用于为单个动画配置水平根运动（Root Motion）的动态缩放范围，使动画根据角色与当前目标之间的距离自动减少或延长移动距离。

它只缩放 animmotion 提供的 X/Y 水平位移：

- 不旋转或改变动画原本的移动方向；
- 不缩放 Z 轴位移；
- 不影响其他动画；
- 必须存在有效的当前战斗目标，才能计算目标距离并执行运动扭曲。

## 2. 注释语法

    animwarp <下限> <上限> [最大角度] [最大距离]

参数均为非负浮点数，表示相对于动画原始水平移动距离的缩放倍率：

- 下限：允许使用的最小倍率；
- 上限：允许使用的最大倍率；
- 最大角度：可选，动画移动方向与目标方向的最大夹角，默认为 60 度；
- 最大距离：可选，角色与目标的当前水平距离上限；
- 必须满足 0 <= 下限 <= 上限。

最大角度必须在 0–180 度之间。最大距离默认为无限制。由于参数按位置
解析，如果需要指定最大距离，必须先明确填写最大角度。

如果省略最大距离，则该规则没有距离上限。如果提供最大距离，当角色与
目标的当前水平距离超过该值时，此条 animwarp 暂时停用，动画按原始根
运动播放。角色重新进入距离范围后，AMR 会重新计算倍率并平滑恢复扭曲。

示例：

    animwarp 0 1

允许把水平位移减少到 0%，但不允许超过动画原始距离。

    animwarp 0.5 1.5

最终水平位移被限制在原始距离的 50% 至 150% 之间。

    animwarp 1 1

强制保持 100% 原始水平位移；动画选择启用运动扭曲，但距离不会被缩放。

    animwarp 0 1.5 60 300

允许 0–150% 缩放，方向夹角不得超过 60 度，并且只在角色与目标的当前
水平距离不超过 300 个 Skyrim 单位时启用。超过任一限制时不执行运动扭曲。

## 3. 倍率计算

AMR 首先根据角色到当前目标的水平距离计算所需倍率：

    请求倍率 = max(0, 目标水平距离 - 停止距离) / 动画原始水平距离

随后使用当前有效的 animwarp 范围限制结果：

    最终倍率 = clamp(请求倍率, 下限, 上限)

最终倍率统一乘到当前动画的 X/Y 累积根运动上。Z 轴保持动画原值。

例如，动画原始水平移动距离为 100：

- 目标需要移动 30，animwarp 0 1 的最终倍率为 0.3；
- 目标需要移动 180，animwarp 0 1 的最终倍率为 1.0；
- 目标需要移动 180，animwarp 0 2 的最终倍率为 1.8；
- 目标需要移动 10，animwarp 0.5 1 的最终倍率为 0.5。

## 4. 时间轴与覆盖规则

animwarp 从该注释自身的时间戳开始生效，并持续有效，直到同一动画中出现后续的 animwarp 注释。

在任意动画时间点，AMR 使用“时间戳已经到达的最后一个 animwarp”。

示例时间轴：

    0.20 秒: animwarp 0 1 45 250
    0.60 秒: animwarp 0.5 1.5 90 400
    1.00 秒: animwarp 1 1

对应行为：

- 0.00–0.20 秒之前：使用默认规则；
- 0.20–0.60 秒：倍率限制为 0–1，最大角度 45 度，最大距离 250；
- 0.60–1.00 秒：倍率限制为 0.5–1.5，最大角度 90 度，最大距离 400；
- 1.00 秒以后：倍率固定为 1。

如果多个 animwarp 位于相同时间戳，则动画数据中排列更后的注释覆盖前面的注释。

切换到新规则时，AMR 会重新对齐已经输出的累积位移，避免倍率变化导致角色瞬移或突然反向拉回。

## 5. 战斗与非战斗动画

### 没有已生效的 animwarp 时

使用默认行为：

- 是否为攻击动画启用默认运动扭曲由 INI 设置控制，默认开启；
- 默认倍率范围由 INI 设置控制，初始值为 0–1；
- 默认角度由 INI 设置控制，初始值为 60 度；
- 使用初始值时，可以把移动减少到 0，但不允许延长。

### 到达 animwarp 时间戳后

该动画主动选择启用运动扭曲：

- 即使角色不处于攻击状态，也允许运动扭曲；
- 即使 INI 禁用了攻击动画的默认运动扭曲，此注释仍会启用当前动画；
- 使用注释指定的倍率上下限；
- 是否允许延长由上限决定；上限大于 1 时允许延长。

因此，非战斗动画只有在时间轴已经到达有效的 animwarp 注释后，才能启用运动扭曲。

## 6. 与 animmotion 的关系

animwarp 本身不会创建根运动。动画仍然需要有效的 animmotion 注释，例如：

    0.00 秒: animmotion 0 0 0
    0.50 秒: animmotion 0 50 0
    1.00 秒: animmotion 0 100 0
    0.00 秒: animwarp 0 1.5

在此例中：

- 动画原始水平移动总距离为 100；
- AMR 可以根据目标距离把水平移动缩放到 0–150；
- 移动方向仍由 animmotion 决定；
- animwarp 不会让角色自动转向目标。

如果动画没有有效的水平 animmotion，或原始水平距离小于配置的最小有效距离，animwarp 不会产生运动扭曲。

## 7. 目标与方向限制

无论是攻击动画还是通过 animwarp 启用的非战斗动画，都必须满足以下条件：

- 角色拥有有效的当前战斗目标；
- 目标没有死亡；
- 目标与角色处于同一 Cell；
- 动画原始移动方向与目标方向之间的夹角没有超过配置上限。

animwarp 只进行缩放，不进行旋转。如果动画方向没有朝向目标，AMR 不会把它强行转向目标。

## 8. Z 轴与悬崖保护

- animwarp 仅缩放 X/Y，动画的 Z 轴根运动保持不变；
- 带有任何 Z 轴根运动的动画会跳过悬崖边缘移动限制；
- animwarp 不会改变这一规则。

## 9. 无效注释

以下注释无效，并会被忽略：

    animwarp -1 1
    animwarp 1 0.5
    animwarp abc 1
    animwarp 0
    animwarp 0 1 -10
    animwarp 0 1 181
    animwarp 0 1 60 -50
    animwarp 0 1 60 300 extra

无效的 animwarp 不会覆盖之前已经生效的有效规则。若动画中没有任何已生效的有效规则，则使用 INI 中配置的攻击动画开关、默认倍率范围和默认角度。

## 10. 推荐配置

仅允许缩短攻击距离：

    animwarp 0 1

避免距离过近时完全停止，同时禁止延长：

    animwarp 0.25 1

允许适度追踪较远目标：

    animwarp 0 1.25

允许较大范围的非战斗对齐：

    animwarp 0 2

建议谨慎使用较大的上限。过度延长会放大动画原始轨迹的所有水平位移，并可能产生明显的滑步或高速冲刺效果。
